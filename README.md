# Surjo

Signed downloads of Surjo, the indoor cycling app, for macOS, Windows and Linux. Each release under [Releases](https://github.com/eric-speelman/surjo-releases/releases) holds:

- `Surjo-<version>-macos.dmg`: for Apple silicon and Intel Macs. Open it and drag Surjo to Applications.
- `Surjo-<version>-windows-x86_64-setup.exe`: for 64-bit Windows 10 and later. It installs for you alone and needs no administrator.
- `Surjo-<version>-x86_64.AppImage`: for 64-bit Linux. Make it executable and run it.
- `SHA256SUMS.txt`: the SHA-256 of each file.

The app's code isn't here; this repository only holds its releases.
